# Student Success Prediction

## Project Description
This project predicts whether a student will pass or fail based on their study hours,attendence , past score , and sleep hours.

## Technologies Used
- Python
- Pandas
- Numpy
- scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Model
- Logistic Regression

## Features
-Study Hours
-Attendence
-Past Score
-Sleep Hours

## Target
- Passed (Yes/No)

 ## Model Performance
 The model achieved approximately 75%
 accuracy on the test data.

 ## How to Run
 1. Install the required  libraries.
 2. Run Student_Success.py
 3. Enter the student's details.
 4. The model predicts whether the student
    is likely to pass or fail.
